Getting started

Run the local Node.js server, then open the player or designer in your browser. A demo project is created automatically on first run.

Playerhttp://localhost:3000/
Designerhttp://localhost:3000/editor.html
Custom host--host=0.0.0.0
# Clone VNFairy
git clone https://github.com/coderkei/VNFairy.git
cd VNFairy

# Install dependencies
npm install

# Start the local server
node server.js

# Optional custom port / host
node server.js --port=8080 --host=0.0.0.0
