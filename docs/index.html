One workspace, many ways to write

Dialogue editor

Cards when you want focus. Script when you want speed.

Write narrator and character lines in a visual flow, then tune each line from the inspector on the right.

  • Search, replace, duplicate, reorder

  • Live stage preview while you author
Made for visual storytelling

Everything around the words belongs in the same flow.

VNFairy brings authoring, presentation, routing, and packaging together without asking you to write a custom engine first.

01

Shape the route

Create scenes and groups, connect choices, add conditional jumps, and see the whole story in a visual map.

02

Compose the stage

Place characters left, centre, or right with expressions, backgrounds, transitions, music, sound, and cutscenes.

03

Track the journey

Use variables, endings, unlockables, gallery content, achievements, and a debug playtest menu for richer routes.

04

Share the finished game

Export a self-contained ZIP for static hosting or run the player offline with the built-in fallback.

No build pipeline required

Open a terminal. Start making.

VNFairy runs on a small local Node.js server. A demo project appears automatically the first time you start it.

Two entry points, one project.

Use the player to play your novels and the designer to create them. When you are ready, Export game produces a static package that can go to GitHub Pages, itch.io, or any web server.

Playerlocalhost:3000/
Designerlocalhost:3000/editor.html
Custom hostnode server.js --host=0.0.0.0
# Clone the repository
git clone https://github.com/coderkei/VNFairy.git
cd VNFairy

# Install and run
npm install
node server.js

✓ Open http://localhost:3000/editor.html
